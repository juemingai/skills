# 设定圣经与续写追踪表

多集、多轮生成时用来保证一致性。项目案阶段生成设定圣经；每次写完一批分集或正文后更新追踪表。

## 设定圣经（项目案附带）

```text
【世界规则】
- 时代/地点/画幅/发行模式
- 世界特殊规则（系统、副本、重生规则、禁忌）及其硬约束
- 规则的代价与例外

【金手指】
- 能力内容
- 使用条件、冷却、次数、代价
- 升级阶梯（第几集段解锁什么）
- 被谁知道、何时暴露

【势力与关系】
- 主要势力及其目标
- 人物关系图（用文字列出：A→B 关系/立场/秘密）
- 每个人物知道哪些秘密、不知道哪些

【时间线】
- 剧内时间跨度
- 关键节点对应的集数
```

## 续写追踪表（每批次更新）

```text
【已写到】第X集，剧内时间：
【人物状态】每个在场人物：当前处境、掌握的信息、对主角的态度
【金手指当前状态】等级/次数/已暴露范围
【已用钩子类型】按集列出，避免连续重复
【已埋伏笔】伏笔内容 → 计划回收集数
【已回收伏笔】
【已倒下的反派】及旁观者反应是否给足
【待办】下一批必须推进的节点
```

## 使用规则

- 用户要求续写且本轮对话里没有追踪表时，先根据已有内容补一份追踪表再写。
- 续写内容与设定圣经冲突时，以设定圣经为准，并向用户指出冲突。
- 用户改了核心设定，先更新设定圣经，再更新受影响的分集。
