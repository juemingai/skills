# 赛道模板

不同赛道的钩子公式、人物功能和情绪节拍差异很大。判定赛道后按对应模板搭结构，不要用无限流模板套女频。

## 赛道判定

| 赛道 | 核心情绪 | 典型钩子 | 一句话梗概公式 |
|------|----------|----------|----------------|
| 男频系统/无限流 | 规则破局、升级 | 副本、系统、金手指 | 主角进入极限处境 + 获得外挂 + 靠信息差破局 + 从求生者变规则挑战者 |
| 男频战神/赘婿 | 身份反差、打脸 | 隐藏身份、龙王归来 | 被轻视的主角 + 真实身份藏而不露 + 每集一次打脸 + 终局身份公开 |
| 女频重生复仇 | 先虐后爽、复仇 | 重生、前世记忆 | 主角前世被害 + 重生回关键节点 + 用先知信息逐个反杀 + 拿回一切 |
| 女频甜宠/闪婚 | 心动、被偏爱 | 契约婚姻、身份误会 | 意外绑定的两人 + 一方隐藏身份 + 误会与心动交替 + 身份揭穿后双向奔赴 |
| 女频虐恋/追妻 | 错过与补偿 | 替身、误会、离婚 | 主角被辜负后离开 + 对方追悔 + 追妻火葬场 + 主角自主选择 |
| 家庭伦理/亲情 | 委屈翻身、认亲 | 真假千金、赡养 | 被亏欠的主角 + 家庭压迫 + 靠真相或能力翻身 + 血缘或情感归位 |
| 悬疑/规则怪谈 | 恐惧与解谜 | 禁忌规则、失踪 | 主角进入异常空间 + 逐条识破规则 + 每次违规有代价 + 真相指向更大局 |
| 职场逆袭 | 打脸、升职 | 顶替、背锅 | 被打压的主角 + 关键能力或后台 + 逐层打脸上司 + 掌握话语权 |

## 人物功能表

男频：
- 主角：爽点执行者，价值选择者。
- 反派梯队：小反派→中 Boss→隐藏 Boss→终 Boss，见 `pacing-and-hooks.md`。
- 盟友：信息线、副本搭档，可牺牲以制造情绪点。
- 墙头草：情绪反复与惩罚对象。

女频：
- 女主：情绪承受者与反击者，必须有自己的目标，不能只等被救。
- 男主：偏爱与救场，但不能替女主完成核心反击。
- 女配/情敌：日常压迫的主要来源，打脸对象。
- 男配/渣男：背叛与追悔，追妻线载体。
- 长辈/家族：阶层压迫与身份认可的发放者。
- 闺蜜/助攻：信息线与情绪出口。

## 情绪线节拍（女频专用）

甜宠：初遇反差 → 被迫同框 → 第一次心动 → 误会 → 偏爱高光 → 身份揭穿 → 危机 → 双向奔赴。
虐恋追妻：辜负 → 离开 → 对方发现真相 → 追悔 → 主角新生活 → 追妻受挫 → 主角自主选择。
重生复仇：前世惨死 → 重生 → 第一次改写命运 → 敌人察觉异常 → 逐个反杀 → 前世真凶浮出 → 终局清算。

女频每 2 集至少一个情感节拍，复仇线和情感线交替推进，不要连续 3 集只有一条线。

## 男频专用规则

- 金手指必须有边界和代价：冷却、次数、等价交换、被发现的风险。没有代价的外挂让后续压迫失效。
- 升级阶梯要可见：等级、称号、资源数字、群聊反应。
- 副本/单元结构：每个单元 3-8 集，单元内有自己的小 Boss 和规则，单元间靠主线秘密串联。

## 各赛道常见踩坑

- 女频用系统音和玩家 ID 传信息：违和，改为手机消息、旁人议论、道具特写。
- 男频主角开场就无敌：没有压迫就没有释放，前 3 集必须被压。
- 甜宠男主替女主打脸：女主失去主体性，观众不代入。
- 复仇剧反派一集就倒：憋屈值不够，反杀不爽。
