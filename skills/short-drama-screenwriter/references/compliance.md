# 内容审核红线与替换策略

短剧上线前要过平台审核和备案。写项目案和正文时主动规避，不要等用户提。本清单是创作参考，不是法律意见；用户明确说明有合规团队兜底时可放宽。

## 高风险题材与替换方式

| 红线 | 常见表现 | 替换策略 |
|------|----------|----------|
| 封建迷信 | 真实存在的鬼神、活人献祭、阴契生效、算命改命 | 落地为骗局、心理操控、家族谋财、科学可解释的异常；或明确为"规则怪谈/游戏世界观"的架空设定 |
| 血腥暴力 | 直接展示肢解、虐杀、大量血 | 用声音、反应镜头、暗示和后果表现，不给正面画面 |
| 色情低俗 | 露骨性描写、强迫情节、擦边台词 | 情感张力靠眼神、距离和台词，不写身体细节 |
| 未成年人 | 未成年角色卷入暴力、恋爱、犯罪 | 主角设定成年；校园题材避免霸凌细节展示 |
| 重生穿越 | 无解释的穿越改变历史、宣扬宿命 | 重生限定在个人命运层面，不触碰真实历史事件和真实人物 |
| 历史/民国/军阀 | 真实历史人物与事件、美化军阀、丑化民族 | 架空地名与人物，不用真实番号和历史事件 |
| 拜金炫富 | 以金钱羞辱为唯一价值观、宣扬不劳而获 | 打脸落点在能力、真相和正义，不只在钱 |
| 家庭伦理极端化 | 婆媳互殴、虐待老人儿童细节、乱伦暗示 | 冲突落在价值观与真相，不放大生理伤害 |
| 违法犯罪美化 | 主角靠犯罪手段翻盘且无代价 | 主角手段在法律边界内，或有明确代价 |
| 政治宗教民族 | 涉及真实政党、宗教仪式、民族对立 | 一律不碰 |

## 自检步骤

1. 项目案阶段：逐条对照上表，标出题材本身触碰的红线，并在"创作思路"里写明处理方式。
2. 正文阶段：检查每一场动作和台词，血腥、色情、迷信描写改为暗示或后果。
3. 用户输入本身踩线（例如"活人献祭"）：不要拒绝，先给出保留原钩子情绪的合规替代方案，再问用户是否接受。

## 民国奇幻类示例

原钩子：村里的阴契和活人献祭。
合规改法：阴契是族长用来控制村民的骗局，"献祭"是掩盖灭口的仪式；主角术士的本事是识破手法与人心，而非真法术。恐怖氛围保留，超自然不落实。
