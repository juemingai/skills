# 需求分析与启发式提问模板

当用户信息不足时，选择最贴近任务的一组问题。一次问 3-6 个，优先问会改变故事方向的问题。一条输入同时命中多组模板时，合并成一次提问，总数仍不超过 6 条，优先保留生产规格、核心钩子和合规口径。触发条件和回复约束见 SKILL.md Step 0，此处不重复。

## 必需项判定示例

输入：`帮我写一个短剧剧本，奇幻探险，惊悚悬疑类型，故事发生时间在民国初期。`
判定：缺主角与核心钩子、缺集数时长与画幅，进入引导模式。

正确响应：
```text
这个方向可以做成"民国奇幻探险 + 民间悬疑禁忌"的短剧。我先确认几个关键点，避免直接写偏：
1. 你想要的目标产物是：完整项目案、分集大纲，还是先写第1集正文？
2. 主角身份更想要哪种：术士/测绘师/记者/军阀副官/民间匠人？
3. 核心悬疑钩子是什么：失踪案、古镇禁忌、阴契、家族秘密，还是其他？
4. 预计多少集、每集多长、横屏还是竖屏？没有的话我建议先按 12 集、每集 1.5-2 分钟、竖屏设计。
5. 发行模式是付费剧、免费剧还是品牌定制？这决定钩子密度和卡点位置。
6. 民俗恐怖题材有审核风险，超自然部分我默认处理为骗局或架空规则，你接受吗？
```

错误响应：直接默认剧名、主角、12 集，并输出项目案或前 3 集正文。

## 用户只有一句创意
示例：`帮我写一个男主无限流求生短剧。`

```text
我先帮你把方向定准。请补充这几个关键点：
1. 主角是什么身份？有没有金手指/外挂？外挂有没有代价或限制？
2. 核心爽点更想要哪种：规则破局、打脸反杀、资源升级、身份反转？
3. 目标产物是项目案、前10集分集，还是直接写第1集正文？
4. 预计多少集、每集多长、横屏还是竖屏、付费还是免费？
```

## 用户提供 IP/小说梗概
```text
我可以按短剧改编来处理。还需要确认：
1. 想保留原作哪些核心名场面或设定？
2. 目标偏男频爽感、女性情绪线，还是男女频融合？
3. 要先出改编案，还是直接拆分集？
4. 是否允许合并/改名/删减配角？
5. 原作里有没有明显触碰审核红线的内容需要改写？
```

## 用户要求写分集
```text
为了避免分集变成流水账，请确认：
1. 要拆多少集？付费剧还是免费剧？卡点位置有没有平台要求？
2. 每集大概 1 分钟、2 分钟，还是更长？
3. 每集结尾要强钩子，还是更偏完整小闭环？
4. 是否已有必须出现的剧情节点或必须倒下的反派顺序？
```

## 用户要求写正文
```text
我可以按短剧正文格式写。请确认：
1. 写第几集？这一集的核心事件是什么？
2. 本集出现哪些角色？如果没给名字，我会帮你起有辨识度的原创角色名。
3. 横屏还是竖屏？场景是否有限制，比如只在宿舍/办公室/家里拍？
4. 结尾想停在哪个钩子上？
```

## 用户要求优化现有剧本
```text
我会从格式、节奏、爽点、可拍性和合规五个方面优化。请确认：
1. 你希望保留原剧情不动，只改表达，还是允许重构剧情？
2. 优先提升哪一项：开场钩子、对白、爽点、结尾钩子、人物弧光？
3. 是否要输出修改后完整正文？
```

## 用户要求续写
```text
为了和前面的集数保持一致，请确认：
1. 已写到第几集？能否把前面的人物表、设定或正文发我？
2. 有没有已经埋下、还没回收的伏笔？
3. 接下来这批要推进到哪个节点？
```

## 默认命名策略
如果用户没有给角色名：
- 根据题材气质命名，不用普通大众名（小明、小美、张伟、李娜、王强之类）。
- 男频无限流可用冷感、锋利、符号感强的名字。
- 女频可用有记忆点但不过度古怪的名字。
- 反派名可体现压迫感、阶层、江湖气或伪善感。
- 名字一旦确定，人物表、分集和正文必须一致。
