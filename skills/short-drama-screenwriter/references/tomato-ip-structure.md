# 项目案结构参考

用于把小说、IP、长梗概或原创脑洞改成短剧项目案。

## 标准项目案结构

```text
假设清单（用户已给全时写"无"）
标题
IP来源（如有）
一、一句话梗概
二、改编思路/创作思路（含合规处理说明）
三、亮点/对标项目
四、集数、时长、画幅、发行模式
五、人物小传
六、设定圣经
七、故事大纲（含终局）
八、全剧节奏表
九、分集概况
```

## 标题
标题要同时给出"高概念钩子"和"情绪承诺"。
- 男频高概念：被拉管理群、全家读心、规则怪谈。情绪承诺：我直接打穿、反手封神。
- 女频高概念：重生回订婚前、闪婚对象是总裁、真千金回归。情绪承诺：这次换你跪、他追悔莫及、全家跪求原谅。

## 一句话梗概
按赛道选公式，见 `genre-tracks.md`。通用骨架：主角身份 + 意外处境 + 核心设定或信息差 + 剧终目标。

## 改编思路
IP 改编时优先说明：
- 保留原作最强钩子和差异化设定。
- 压缩重复关卡和流水账支线。
- 合并功能相近的配角。
- 强化阶段性反派和主角队友的角色弧光。
- 以"单元/副本 + 主线推进"或"复仇节点 + 情感线"适配短剧节奏。
- 原作触碰审核红线的部分如何处理，见 `compliance.md`。

## 亮点
常见亮点维度：
- 设定：规则、外挂、身份、系统、反转机制。
- 爽点节奏：信息差、资源差、身份揭示、打脸反杀。
- 情绪价值：压迫、背叛、救赎、复仇、守护、偏爱。
- 群像：盟友、墙头草、宿敌、隐藏 Boss。
- 拍摄可行性：集中场景、道具复用、低成本高概念表达。

## 人物小传
每个角色建议包含：
```text
姓名（ID/称号） 性别，视觉年龄，原职业/身份，剧情定位
外貌气质与性格
能力/资源/秘密
与主角关系
成长、堕落或反转弧
所属反派层级（反派填写：小反派/中Boss/隐藏Boss/终Boss）及倒下集数段
```

## 设定圣经
结构见 `story-bible.md`。题材涉及系统、副本、重生规则、超自然或多势力时必须写；纯现实题材可简化为"世界规则 + 人物关系图"。

## 故事大纲
大纲不要只复述事件，要写清阶段推进并写到结局：
1. 主角进入危机，获得核心外挂/目标。
2. 第一阶段熟悉规则，拿到关键资源，击败小反派。
3. 中段被背叛/围猎/规则升级，主角靠信息差破局，击败中 Boss。
4. 中点反转：隐藏 Boss 浮出，主角认知被颠覆。
5. 终局冲刺：伏笔回收，与终 Boss 对决。
6. 结局：主线目标落地，反派下场，情感或价值选择收束。

## 全剧节奏表
分集前先出，格式见 `pacing-and-hooks.md`。

## 分集概况
每集 1-2 句话，必须包含本集推进点和结尾钩子类型。推荐句式：
```text
第X集：主角因【事件】进入【冲突】，利用【信息差/资源/选择】完成【破局/反转】，结尾【钩子类型：具体钩子】。
```

连续三集示例（女频重生复仇，展示钩子串联与类型轮换）：
```text
第1集：沈知微订婚前夜被闺蜜林思思与未婚夫顾承宇联手杀害，重生回订婚前一天，当场答应让林思思"试穿"自己的礼服。结尾【情感钩子：她笑着把礼服递给仇人】。
第2集：订婚宴上林思思穿着礼服登场，沈知微当众宣布礼服里缝着顾承宇送给林思思的定情信物，宾客哗然。结尾【反派亮牌：顾承宇冷笑，说股权转让书已经签好】。
第3集：沈知微拿出前世记忆里的原件位置，证明转让书签名是伪造，顾承宇被沈父当场逐出宴会。结尾【身份揭示：一个陌生男人递来名片，说他知道沈知微"死过一次"】。
```
每集结尾钩子直接成为下一集的开场事件，三集钩子类型各不相同。
